# AZAZEL BAILEYS (`danzznotalone/baileys`)

Custom WhatsApp Web Multi-Device API Engine by **Danzz** — mendukung protokol WhatsApp terbaru (November 2026), arsitektur *anti-logout*, *silent console banner*, serta pengiriman semua tipe *payload* dan *rich message*.

- **Telegram Channel:** [t.me/azazelnewera](https://t.me)
- **Update Baileys:** [t.me/updatebaileysdanzz205](https://t.me)

## Fitur Utama
- **Azazel Red Mask Banner:** Menampilkan banner berwarna 1x saat *install* maupun `npm start` tanpa *spam log* di konsol.
- **Anti-Logout Engine:** *Heartbeat* teroptimasi dan pemulihan sesi otomatis tanpa terputus.
- **Custom Pairing & QR:** Mendukung *custom pairing code* 8 digit maupun QR sesuai konfigurasi *script* bot.
- **Global Number & Group Link:** Kirim langsung ke nomor `+628xxx`, `628xxx`, nomor luar negeri, maupun link grup (`https://chat.whatsapp.com/...`).
- **Anti-Empty Sender Guard:** Mencegah pengiriman pesan kosong (kecuali mode `invisible`).
- **Full Payload Support:** Mendukung *Rich Interactive Message*, *Pop-up JS + Audio Auto-Play*, *Anonymous Relay*, dan *Invisible Protocol*.
